# Catalyst Phase 1 reader rubric

Read the complete stored conversation and its evidence before comparing model
teams. Do not turn this review into a numeric score, pass percentage, ranking,
or automatic winner.

For each case, explain:

1. whether the response addressed the user's actual request;
2. whether the selected SQL and returned rows or database error agree with the
   scenario's static design-time reference or reviewed expected response;
3. whether later turns retained relevant earlier instructions without carrying
   unrelated constraints into a new question;
4. whether a clarification or unsupported response was appropriate and
   contained no new SQL; and
5. any important limitation in the available evidence.

Then compare the selected complete model setups. A preference is optional. If the
evidence supports one, state the practical reason and the tradeoffs. If it does
not, explain what remains uncertain. Wrong answers remain experiment results;
collection problems are described separately and are not treated as model
behavior.
