The project

Build clinical AI that can be inspected, tested, and run close to care.

Open Clinical AI connects small, locally runnable language models to real clinical systems, then checks their answers against the same source evidence a clinician can inspect.

The project is not a claim that a model is ready to practice medicine. It is a practical environment for learning what works, where it fails, and which safeguards make a measurable difference.

01

Local by design

Models and patient context can remain within the deployment instead of depending on a remote AI service.

02

Evidence before confidence

Answers expose the chart records used, while deterministic checks catch high-confidence temporal and formatting errors.

03

Measured in context

Real clinical questions run through the actual integration and are reviewed cell by cell, not reduced to one opaque score.

Med Agent Hub

One service coordinates the clinical answer path.

Med Agent Hub is the model-facing service behind the demo. It retrieves clinical context, builds structured temporal facts, runs the selected model profile, checks the output, resolves evidence, and prepares an in-depth response.

1 Context

Gather patient records and source provenance.

2 Answer

Return a focused answer from the configured model profile.

3 Check

Apply deterministic temporal and answer-quality rules.

4 Evidence

Resolve citations and attach final grounding status.

5 In-Depth

Expand from the final checked answer when requested.
