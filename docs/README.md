# User-Facing Documentation

This directory is reserved for user-facing documentation: quickstarts, operator
guides, usage notes, and externally useful explanations.

Planning artifacts, feature/milestone specs, governance templates, research
canvases, and handoff snapshots belong in `specs/`.

- [Catalyst demo operations](catalyst-demo-operations.md): current server, SSH,
  isolated lifecycle, ARM compatibility, retained data and video publication.
